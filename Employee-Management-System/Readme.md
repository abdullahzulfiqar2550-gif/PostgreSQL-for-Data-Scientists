# Employee Management System

A database-driven employee management application built with **Python, Streamlit, PostgreSQL, and psycopg2**.

* Perform complete **CRUD operations** on employee records.
* Filter and sort employees based on their scores.
* Calculate **total, maximum, minimum, and average scores** using SQL.
* Visualize employee performance through interactive **bar charts**.
* Provides an interactive Streamlit UI connected directly to PostgreSQL.
* Demonstrates practical integration of **Python, SQL, databases, and data visualization**.

**Tech Stack:** Python | Streamlit | PostgreSQL | psycopg2 | SQL
